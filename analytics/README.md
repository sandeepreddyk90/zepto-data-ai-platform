# Titanic analytical workflow

Run `python analytics/01_eda.py` then `python analytics/02_modeling.py` from the project root. The first script calls Seaborn's loader only if `titanic.csv` is absent or `--refresh` is explicitly supplied; it immediately saves the raw dataset as the offline fallback. It profiles/cleans the one dataset, records numerical results and chart interpretations in `eda_results.md`, and passes `titanic_clean.csv` to the modeling script. The latter writes `model_results.md` with held-out results, classifications, tuning, regression and recommendation, and saves an end-to-end pipeline as `best_pipeline.joblib`.

All charts in `charts/` supplement written interpretations. The two `*_results.md` files are generated from the actual run so reported numbers reflect the committed CSV and environment. EDA imputes age for exploratory charts; modeling keeps those missing ages and learns its median only on training folds, preventing a full-data EDA statistic from leaking into model evaluation. The saved artifact loads with `joblib.load('analytics/best_pipeline.joblib')` and accepts a DataFrame with raw `pclass`, `age`, `sibsp`, `parch`, `fare`, `sex`, `embarked` columns.
