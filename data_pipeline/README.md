# Catalogue data pipeline

Run `python data_pipeline/pipeline.py` from the repository root. It discovers category URLs, follows pagination for Sequential Art, Mystery and Historical Fiction, saves cleaned rows to `books_clean.csv`, recreates `books.sqlite`, then writes five executed SQL queries and outputs to `query_results.md`. The two-table schema uses a category foreign key with SQLite foreign keys enabled. It drops rows with unparsable required fields because inventing a product's price, rating or stock status via median imputation would distort catalogue comparisons; the count is logged. Duplicates are constrained by the product URL. The fixed assignment conversion is **1 GBP = 105.50 INR**. The site must be reachable when regenerating the database; saved CSV and query transcript document the last successful run.
